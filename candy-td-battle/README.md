# 🍬 糖果塔防对战（Candy TD Battle）V2

面向情侣与双人好友的 PC 桌面浏览器轻量级高颜值实时 1v1 策略塔防对战游戏（附带单人 AI 陪练模式）。

## 快速启动

```bash
npm install
npm start
```

默认监听 `http://127.0.0.1:3000`（支持环境变量 `PORT` 覆盖，例如 `PORT=3100 npm start`）。

### 测试模式与自动化测试

- **运行自动化单测与 WS 协议集成测试**：
  ```bash
  npm test
  ```
- **开启受控测试钩子启动服务端**（仅测试验收使用，生产模式严禁开启）：
  ```bash
  npm run start:test
  ```
  浏览器访问 `http://127.0.0.1:3000/?test=1` 即可挂载 `window.__CANDY_TEST__`（需同时满足服务端 `CANDY_ALLOW_TEST_HOOKS=1` 与 URL `?test=1` 双门控，包含 `getViewState()` 等只读/仿真钩子）。
- **性能诊断浮层**：在任意局 URL 后附加 `?netdebug=1` 显示 `FPS / Render(ms) / RTT(ms) / ServerTick(ms) / DPR / Entities`。

## V2 核心玩法要点

1. **8 张甜品主题地图与随机选图**：大厅与 PvP 等待房提供带迷你路径缩略图的 8+1 选图器（经典 S 弯、华夫折返廊、彩虹双拱门、千层阶梯道、双谷夹心道、奶油皇冠峰、焦糖马蹄环、饼干折扇道，或 `🎲 随机地图`）。
2. **$190 开荒与 Lv3 双分支转职（快捷键 `1-4`）**：
   - 🍓 **草莓豆豆炮（`$80`）**：高频破盾，Lv3 分支 `A` 加特林叠伤炮 / `B` 碎糖削甲散射。
   - 🍨 **薄荷冰淇淋（`$100`）**：Lv1 起带全队乘法易伤（+12%/+20%），Lv3 分支 `A` 极寒冰环冻结 / `B` 脆糖催化（+35% 易伤+死亡冰爆）。
   - 🍿 **焦糖爆米花（`$140`）**：群体 AOE 清线，Lv3 分支 `A` 焦糖岩浆池（穿盾 DoT）/ `B` 连锁跳跳糖 4 弹跳。
   - 🍋 **柠檬破甲狙（`$190`）**：超远破甲激光，Lv3 分支 `A` 蓄力穿透光束 / `B` 终结斩杀狙（Boss+25% 与 <30% 血 1.75× 处决）。
3. **明牌增益障碍物拆迁（`$60`）**：每张图 4 个甜品障碍物角落均明牌标出下方增益（`🎯` +20% 射程 / `⚡` +20% 攻速 / `🔥` +15% 伤害 / `💰` +$3 击杀掉金），点击障碍物确认拆迁后永久保留，出售防御塔后增益格依然有效。
4. **5 大暗黑霓虹突袭部队（快捷键 `Q/W/E/R/T`）**：
   - 派怪给对手永久提升己方每 6 秒 `Eco`，且暗袭怪**防卫赏金恒为 `$0`**（彻底杜绝互刷）。
   - `R`（💚 暗黑奶妈车）与 `T`（🛡️ 终极铁王八）提供 3 秒快递车与明确车种图标预警。
5. **对称双侧锁定视角切换 & 悬停图鉴**：
   - 移入右侧「👀 查看对手 →」热区或按 `Space` 锁定进入对手视角（悬停看对手塔只读信息与射程圈，点击棋盘 0 误建）；移入左侧「← 返回己方」热区 / 再按 `Space` / `Esc` / `1-4` 平滑回防。
   - 悬停底栏 9 张卡片弹出不遮挡按钮的详细 Tooltip；点击顶部 `❓` 可随时打开 3 Tab 玩法与怪物图鉴。

## 子路径反向代理部署

前端资源均采用相对路径，WebSocket URL 自动依据 `window.location` 推导（例如部署于 `https://example.com/candy-td/` 时自动连接 `wss://example.com/candy-td/ws`），服务端兼容带前缀与剥离前缀的 `/ws` 升级请求。
