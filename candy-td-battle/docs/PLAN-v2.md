#### 核心战斗结算顺序与公式（权威仿真唯一标准）
1. **塔有效面板（含增益格）**：
   - `effRange = baseRange * (buff === 'range' ? 1.20 : 1)`
   - `effRate = baseRate * (buff === 'rate' ? 1.20 : 1)`
   - `tileDmgMult = (buff === 'damage' ? 1.15 : 1)`
2. **次数护盾拦截（先于扣血）**：
   - 若目标 `shieldHits > 0` 且命中属于离散直接打击（非 DoT 持续灼烧）：`shieldHits -= 1`，**本次伤害完全被护盾吸收（扣血 `0`）**，触发 `shield_hit`（破至 0 触发 `shield_break` 爆裂特效）；薄荷减速/易伤与草莓-B 碎甲减益仍在破盾瞬间施加（确保辅助价值）。
   - 焦糖-A 岩浆池 DoT（每 `0.25s` = `5 ticks` 结算一次）：不消耗 `shieldHits`，当目标有盾时造成 `50%` 灼烧伤，无盾时造成 `100%` 灼烧伤。
3. **最终伤害公式（破盾后）**：
   - `armorMult`：无甲 `1.0`；柠檬塔打硬甲/重甲为 `lv.armoredBonus`（`1.6 / 1.8 / 1.9`）；其他塔打被草莓-B 碎甲目标为 `0.85`，否则打常规硬甲为塔自带倍率（草莓 `0.65`、薄荷 `0.60`、爆米花 `0.55`），打铁王八重甲（`heavyArmor`）为 `0.50`（碎甲后 `0.75`）。
   - `vulnMult`：非薄荷塔命中带易伤目标时 `× (1 + creep.vulnBonus)`（最高取当前有效薄荷易伤 `+12% / +20% / +22% / +35%`，不同源取最大、刷新时间不无限累加）。
   - `specialMult`：草莓-A 连续锁定叠加（`1 + 0.10 * Math.min(10, stacks)`）；柠檬-B 对 Boss/精英 `×1.25`、对 `<30%` 血量 `×1.75`。
   - `finalDamage = baseDamage * tileDmgMult * armorMult * vulnMult * specialMult`。
4. **减速与冰冻抗性**：
   - `neon_dasher`（极速突袭）：`progress < 0.30` 期间免疫减速与冰冻；`progress >= 0.30` 后 `effectiveSlow = slowPct * 0.5`。
   - `iron_titan`（铁王八 Boss）：全程 `effectiveSlow = slowPct * 0.5`，冰冻时长减半（`0.5s`）。
   - 冰冻期间（`freezeTicks > 0`）移速为 `0`；普通怪冻结 `1.0s`（`20t`），Boss/抗减速怪冻结 `0.5s`（`10t`），同一单位被解冻后有 `2.5s`（`50t`）冰冻免疫窗防无限控死。

### 3.5 平滑难度曲线（W1–W15 经脚本精确验证 + W16+ 温和加时）

### 3.6 障碍物拆迁与隐藏增益格机制
- **拆迁操作**：在己方视角下（且未选中建塔预览时，或直接左键点击障碍物格），点击尚未拆除的甜品障碍物弹出「拆迁浮卡」：显示障碍物名称、费用 **`$60`** 及「拆除后将揭晓隐藏增益格并可建塔」提示；点击「💰 拆迁 `$60`」发送 `demolish_obstacle`。
- **服务端权威校验**：校验 `PLAYING` 阶段、坐标属于当前 `mapId` 的障碍物、该玩家尚未拆除过该坐标、金币 `≥ $60`；扣款后加入 `player.clearedObstacles`，广播 `obstacle_demolished` 事件（含揭晓的 `buffType`）并在前端播放糖果碎裂粒子 + 金色光环浮字（如 `✨ 发现 +20% 射程晶格！`）。
- **4 种增益格精确效果**：
  1. `range`（🎯 **射程晶格**）：该格塔最终射程 **`×1.20`**（视觉：青蓝瞄准星地砖 + 塔底星环）。
  2. `rate`（⚡ **极速糖格**）：该格塔最终攻速 **`×1.20`**（视觉：粉金闪电地砖 + 塔底脉冲）。
  3. `damage`（🔥 **烈焰糖格**）：该格塔最终伤害 **`×1.15`**（视觉：暖橙火焰地砖 + 塔底辉光）。
  4. `bounty`（💰 **招财金格**）：该格塔**完成自然怪最后一击**时额外掉落 **`+$3`** 金币（对玩家暗袭怪不触发防刷钱；视觉：金箔四叶草地砖）。
- **持久性**：增益格一经拆出本局对应该玩家永久保留；出售该格上的塔后增益格仍在，可改建其他塔享受增益。

### 3.9 单人 AI 陪练重构（动态路径评分 + 新机制全适配）

- **两档性格差异（彻底移除假动作）**：

## 6. 构建模式建议

- **推荐模式：单 Builder（`Hydrogen`，high effort）按 3 层顺序稳健实现**。
- **选择理由**：V2 改动横跨共享常量（`constants.js`）、仿真内核（`simulation.js`）、选图房间（`room-manager.js`）、AI（`ai-bot.js`）以及前端渲染/交互/UI（`renderer.js`, `input.js`, `ui.js`, `index.html`, `style.css`），模块之间强耦合于统一的 8 地图模型、塔分支结构与 WS 协议字段。单 Builder 按 **`Layer 1（constants 8 图 + 塔分支 + 暗袭怪 + 波次曲线 + simulation + sim-unit 单测全绿）` → `Layer 2（room-manager 选图 + 动态 AI + ws-protocol 集成测试全绿）` → `Layer 3（居中对称画布 + 动态障碍精灵 + 锁定视角 + Tooltip + 怪物图鉴 + 音效 + 浏览器交互自测）`** 推进，既零契约错位、零分支合并冲突，又方便每一层独立跑通回归测试。
