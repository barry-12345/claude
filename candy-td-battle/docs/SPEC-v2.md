#### 核心战斗结算顺序与公式（权威仿真唯一标准）
1. **塔有效面板（含增益格）**：`effRange = baseRange * (buff === 'range' ? 1.20 : 1)`；`effRate = baseRate * (buff === 'rate' ? 1.20 : 1)`；`tileDmgMult = (buff === 'damage' ? 1.15 : 1)`。
2. **次数护盾拦截（先于扣血）**：若 `shieldHits > 0` 且命中属于离散直接打击（非 DoT 灼烧）：`shieldHits -= 1`，**本次伤害完全被护盾吸收（扣血 `0`）**，触发 `shield_hit`（归零触发 `shield_break`）；薄荷减速/易伤与草莓-B 碎甲减益仍在破盾瞬间施加。焦糖-A 岩浆池 DoT（每 `5 ticks` = `0.25s` 结算一次）不耗盾，有盾时造成 `50%` 灼烧伤、无盾造成 `100%`。
3. **最终伤害公式（破盾后）**：
   - `armorMult`：无甲 `1.0`；柠檬塔打硬甲/重甲为 `lv.armoredBonus`（`1.6 / 1.8 / 1.9`）；其他塔打被草莓-B 碎甲目标：常规硬甲 `0.85`、铁王八重甲 `0.75`；未碎甲时：草莓打硬甲 `0.65`、薄荷 `0.60`、爆米花 `0.55`，打铁王八重甲统一 `0.50`。
   - `vulnMult`：非薄荷塔命中带易伤目标时 `× (1 + creep.vulnBonus)`（取当前有效薄荷易伤最大值 `+12% / +20% / +22% / +35%`）。
   - `specialMult`：草莓-A 连续锁定叠加（`1 + 0.10 * Math.min(10, stacks)`）；柠檬-B 对 Boss/精英 `×1.25`、当前 HP `< 30%` 时再 `×1.75`。
   - `finalDamage = baseDamage * tileDmgMult * armorMult * vulnMult * specialMult`。
4. **减速与冰冻抗性**：`neon_dasher` 在 `progress < 0.30` 期间免疫减速与冰冻，`progress >= 0.30` 后减速效果减半（`slowResist: 0.5`）；`iron_titan` 全程 `slowResist: 0.5`、冰冻时长减半（`0.5s`）；所有单位解冻后享有 `2.5s`（`50t`）冰冻免疫窗。

### 3.6 明牌增益障碍物拆迁机制（已定稿 `1B`）
- **拆迁前明牌预告**：棋盘上每个未拆除的甜品障碍物右下/右上角均绘制清晰的高对比度**增益小徽章**（`🎯` 青蓝射程 / `⚡` 粉金攻速 / `🔥` 暖橙伤害 / `💰` 金箔掉金），玩家无需盲猜即可一眼规划拆迁顺序。
- **拆迁操作**：在己方视角下左键点击未拆除的障碍物，弹出「障碍拆迁浮卡」：显示障碍物名称、**明牌预告拆迁后解锁的具体增益名称与数值**（如 `解锁：🎯 射程晶格（+20% 射程）`）以及「💰 拆迁 `$60`」按钮；点击确认发送 `demolish_obstacle`。
- **服务端权威校验**：校验 `PLAYING` 阶段、坐标属于当前 `mapId` 的障碍物、该玩家尚未拆除、金币 `≥ $60`；扣款后加入 `player.clearedObstacles`，广播 `obstacle_demolished` 事件，前端播放糖果碎裂粒子 + 浮字提示（如 `✨ 已解锁 🎯 射程晶格 (+20%)`）。
- **4 种增益格精确效果**：
  1. `range`（🎯 **射程晶格**）：该格塔最终射程 **`×1.20`**。
  2. `rate`（⚡ **极速糖格**）：该格塔最终攻速 **`×1.20`**。
  3. `damage`（🔥 **烈焰糖格**）：该格塔最终伤害 **`×1.15`**。
  4. `bounty`（💰 **招财金格**）：该格塔**完成自然怪最后一击**时额外掉落 **`+$3`** 金币（对玩家暗袭怪不触发防刷钱）。
- **持久性与独立性**：拆迁仅影响拆迁方自己棋盘；增益格一经拆出本局永久保留，出售该格防御塔后增益格仍在，可改建其他塔继续生效。
