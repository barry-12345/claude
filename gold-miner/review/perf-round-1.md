返工项:

【问题 1(必须):90 Hz / 100 Hz 屏幕上,帧率减半,还会被误降到最低画质】
- **现象和证据**(`p6-hz.js`,本地对战,画布很小,绘制远快于刷新间隔,也就是"快机器")
  | 屏幕 | 改动前 | 改动后 |
  |---|---|---|
  | 90 Hz,DPR2 | 每秒绘制 89.7,画布 960 宽 | 每秒绘制 45.1,并在 2 秒后自动降到第 2 档(画布 480 宽,1 倍,Retina 上变糊);记录的降档原因是"中位数 22.2 ms" |
  | 90 Hz,DPR1.25(常见 Windows 笔记本缩放) | — | 45 FPS,降到第 2 档 |
  | 100 Hz,DPR2 或 DPR1.5,带 0.3–0.5 ms 抖动 | 每秒绘制 99.9 | 50 FPS,也降到第 2 档(中位数 20.0 ms 刚好超过 20 ms 门槛) |
- **原因**
  - `frame()` 里 `now - last < 12` 就跳过这一帧。90 Hz 的帧间隔是 11.1 ms,100 Hz 是 10 ms,所以每两帧跳一帧,实际只画 45/50 帧。
  - 跳过以后,降档逻辑测到的帧间隔变成 22.2/20 ms,超过"中位数 > 20 ms"的门槛,就把快机器当成慢机器降了档。
- **为什么是问题**
  - 90 Hz、100 Hz 屏幕并不少见:不少国产轻薄本是 90 Hz 高分屏,100 Hz 外接显示器也很常见。
  - 在这些电脑上,本轮改动让游戏比改动前更卡(帧率减半)、更糊(降到 1 倍分辨率),正好违背了这次优化的目的。
  - 对方用什么电脑我们并不知道。
- **修改方向**
  - 绘制上限改成"按 60 Hz 节拍取帧",例如用累计时间判断是否到了下一个 1/60 秒,而不是"间隔 < 12 ms 就跳过"。这样 90 Hz 画 60 帧,100 Hz 画约 60 帧,120 Hz 画 60 帧,60 Hz 不受影响。
  - 也可以只在测出刷新率 ≥ 110 Hz 时才启用上限。
  - 自动降档应当衡量绘制本身的耗时(或者扣除主动跳过的帧),不能把"主动跳帧造成的间隔"当成慢帧。
- **验收标准**(下一轮用 `p6-hz.js` 复测,需重建 a52c495 之后版本的 worktree)
  - 在小画布(快机器)、DPR2 和 DPR1.25 下:
    - 模拟 60、60(抖动 15–18 ms)、75、90、100、120、144 Hz,每秒绘制 ≥ min(刷新率, 57),120/144 Hz ≤ 75;
    - 15 秒内 `G.perfLevel` 保持 0;
    - 游戏时间 8 秒走 8.00 ± 0.05 秒。
  - 构建者自己的 perf-probe 里,DPR2 1728×1117 4× 降速仍然能自动降档,FPS 不低于本轮(约 14 FPS 以上)。
  - `online` 关键用例以及 `phase2`、`shots` 仍然通过。

建议项(不阻塞交付,作为已知问题告诉用户):

1. **只降不升**:短暂卡一下(例如切回标签页的头几帧;已排除隐藏和暂停期间)可能让本局剩下的时间都用较低分辨率,刷新页面恢复。可以考虑连续若干个窗口都很快时升回一档。
2. **更大的收益在物品绘制**:构建者的拆分显示,物品约占整帧 60–65%。把每种物品按当前缩放预渲染成精灵图(闪光另外叠加)预期能把绘制成本再降一半左右,但这不是一行级改动,风险中等,不要求本轮做。
3. **我试过的一行级优化没有收益**:`getContext('2d', { alpha: false })` 在 3456 宽画布上来回对比是 38.6/45.9 FPS 对 44/45.4 FPS,在噪声范围内。另外,对局画面里没有 `shadowBlur`(只在菜单、选人、商店的选中框里用到)。没有发现被遗漏的一行级大头。
4. **O-13** 维持「建议」(同前几轮)。
5. **更新前的提醒**:确认服务器上的 clone 在 `claude/adoring-albattani-ob33dp` 分支上(`git -C ~/goldminer-src branch --show-current`);更新时不要有人正在对局。

给用户的摘要:

这一轮的性能优化方向是对的:在 Retina 大窗口这种最常见的"卡"的情况下,自动降低画布分辨率后,帧率从约 35 提升到 43,稳定到最低档后接近 60;普通 1080p 屏幕和快的电脑不受影响,点击位置和缩放窗口都正常,原有玩法和联机测试没有回归。但新加的"最多画 60 帧"有个副作用:在 90 Hz 或 100 Hz 屏幕上(不少笔记本和显示器是这种),帧率反而减半,还会把画面降成最糊的一档。修起来只要改一两行,建议修好再更新到服务器。修好后的更新命令就是 `cd ~/goldminer-src && git pull && cd gold-miner && sudo bash deploy/update-online.sh`(不要在对局中运行),已打开的页面刷新一下即可。
