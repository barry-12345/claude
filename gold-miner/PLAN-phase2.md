## 1. 技术路线

- 仍是单文件 `index.html`,在第一阶段代码上扩展,不重写。
- **第 0 步(Builder 必做)**:把第一阶段验收通过的 `index.html` 原样复制为 `tests/baseline-phase1.html`。
- **规则集表驱动**:新增 `RULESETS = { v1: {...}, v2: {...} }` 和 `RULE_VERSION = 2`。凡是本阶段改动的数值或开关,都从当前规则集 `R` 读取:
  - 开关:`combo / finale / rhythm / bounce / feel`;
  - 目标数组;
  - 物品数量与保底系数;
  - 物品权重倍率;
  - 白给物品数值;
  - 空钩速度;
  - 商店涨价率;
  - 星级倍率。
- `v1` 必须**精确等于**第一阶段的行为(全部开关关闭、旧数值)。`v2` 是本方案。默认 `v2`;URL `?rules=v1` 或 `__game.setRules('v1')`(只在 start 屏有效)切换。第三阶段排行榜的 `version` 字段就存 `RULE_VERSION`。
- **随机数分流**:新增的纯视觉随机(粒子、震屏、金币雨等)一律用独立的 `fxRand`(`mulberry`,种子由 `seed+1` 派生),**不得**消耗 `Math.random()`。这样开关"减少特效"不会改变游戏结果(见 AC-P2-07)。
- 所有新增逻辑只依赖 `update(dt)`,保证 `advance()` 与实时运行一致。

## 2. 五个新机制(三个模式都生效)

### 2.1 #1 连击倍率

| 项 | 规则 |
|---|---|
| 归属 | **每个玩家各自一条连击**(合作也是各算各的,体现个人发挥) |
| 好货(连击 +1) | 交付时基础价值(`pieceValue`,未乘倍率)≥ $100 的物品:中/大/巨金块、各种宝石、宝箱、化石、冰封金块、金猪、象牙、黑曜石、火龙蛋、圣甲虫、黄金面具、陨石金、背金乌龟、钻石鼹鼠;磁石按"本体+吸附"总价判断 |
| 中性(不加不断) | 小金块($50)、神秘袋、金蛋、沙漏、四叶草、神灯、闪电瓶、价值 < $100 的其它物品 |
| 垃圾(连击清零) | 小/大石头、旧靴子、骷髅头、生锈铁锚、木乃伊、鼹鼠、碎石 |
| 空钩(清零) | 钩子空手收回:没碰到东西、被石门挡住、被岩浆击退、碰到 TNT |
| 空钩(中性) | 用炸药炸掉手里的东西、拔河输了被抢走、合作中作为帮手合力结束 |
| 倍率档位 | 连击 ≥3:×1.25;≥5:×1.5;≥8:×2.0(上限)。先 +1 再按新档位计算,所以第 3 件好货就吃到 ×1.25 |
| 叠加 | 依次相乘:基础价值(含淘金热、黄金尾声、鉴定书等)× 四叶草 ×2 × 连击倍率 × 反弹 ×1.25。例:黄金面具 $800 × 四叶草 2 × 连击 2.0 × 反弹 1.25 = $4,000 |
| 合作合力 | 倍率用**持钩者**的连击;算好倍率后再按现有规则平分;帮手的连击不变 |
| 拔河 | 胜者按物品正常计连击,输家中性 |
| 每关开始 | 清零 |
| 单人星级 | 连击加成计入本关收入,所以会影响星级 |
| 角色 | 无专门改动(老金瞄得准,天然更容易保连击) |
| HUD | 玩家面板下方有连击条:"连击 5 ×1.5",升档时闪光;清零时灰字"连击中断"加一声低沉音效 |

### 2.2 #3 绞盘节奏

| 项 | 规则 |
|---|---|
| 何时出现 | 自己的钩子在**拉回重量 ≥3 的物品**时(大金块、巨金块、石头、化石、宝箱、象牙、黑曜石、火龙蛋、黄金面具、木乃伊、铁锚,以及吸附后变重的磁石) |
| 节拍 | 从抓住物品起算,每 **0.5 秒**一拍;第一拍在 0.5 秒 |
| 判定窗口 | 离最近一拍 **±0.07 秒**以内按发射键(S 或 ↓)算"踩点" |
| 踩点 | 拉速 **×1.6**,持续 0.6 秒(再踩点会刷新) |
| 踩空 | 拉速 **×0.25**,持续 0.4 秒,并立刻取消加速(按得太早也算踩空) |
| 不按 | 正常速度,没有惩罚 |
| 叠加 | 依次相乘:基础拉速 × 大力药水 × 大力熊被动 × 合作合力 ×2 × 节奏 |
| 和拔河的冲突 | 没有冲突。拔河时钩子状态是 `tug`,发射键只算拔河狂按;拔河结束后,赢家拉回时从 0 重新计拍 |
| 合作合力 | 只认**持钩者**的按键,帮手按键无效 |
| 冻结 | 被闪电冻结时按键无效 |
| 设计目的 | 把干等 10 秒变成小游戏;同时**惩罚狂按**:实测狂按机器人踩空率约 70%,反而拉得更慢 |
| 表现 | 绞盘外圈一个收缩光圈,在节拍时刻和外环重合;踩点显示"节奏 ×N"和清脆咔哒声;踩空显示"卡住!"和闷响。停电时光圈画在黑暗层之上 |

### 2.3 #4 黄金尾声

| 项 | 规则 |
|---|---|
| 触发 | 剩余时间第一次 ≤ **15 秒**时(快速模式按 `ROUND_TIME/60` 缩放),每关一次 |
| 效果 1 | 屏幕一震,横幅"黄金尾声!",场地**深处(y ≥ 430)**涌出新物品,数量:第 1–2 关 3 个,第 3–5 关 4 个,第 6–8 关 5 个 |
| 物品种类 | 中金块 40%、大金块 25%、红宝石 10%、翡翠 10%、钻石 10%、巨型金块 5% |
| 位置 | 用 `freeSpot`(避开现有物品和危险物,保证存活玩家能够到);同一物品最多试 30 次找 y ≥ 430 的位置,找不到就跳过 |
| 效果 2 | 尾声期间,所有金块类(`GOLD_TYPES`,含冰封金块)价值 ×1.5,与淘金热相乘(最高 ×2.25) |
| 沙漏 | 尾声开始后再加时间,尾声照样持续到本关结束 |
| 事件 | 地震洗牌会连尾声物品一起洗;停电时尾声物品自带一圈小光晕 |
| 对战 | 两人抢同一批 |
| 设计目的 | 把每关最后一段"捡石头"变成冲刺;放在深处是为了奖励瞄准,狂按很难拿到 |

### 2.4 #7 反弹钩

| 项 | 规则 |
|---|---|
| 反弹 | 伸出中的钩子第一次碰到**左右边界**时镜像反弹(角度取反),继续伸出;每次发射**最多反弹 1 次**,第二次碰墙或碰底就正常收回 |
| 射程限制 | 反弹后最多再伸 **450 px**,超过就空手收回 |
| 奖励 | 反弹后抓到的物品,价值 **×1.25**,显示"花式!";按好货/垃圾正常计连击 |
| 几何 | 钩子记录反弹点 `(bx, by)`、反弹时长度 `blen`、新角度 `a2`。`hookTip` 在 `len > blen` 时返回 `B + (len−blen)·(sin a2, cos a2)`;收回到 `len ≤ blen` 时清除反弹状态。绳子画两段:支点→反弹点→钩尖 |
| 石门 | 判定照旧只看钩尖位置,所以反弹后那一段同样会被关着的石门挡住。反弹的价值在于换角度去够石门侧面或后面的东西 |
| 岩浆 | 照旧检查钩尖和物品;绳子穿过岩浆柱不算 |
| 冰原偏移 | 偏移继续作用,反弹后方向镜像(`a2 −= driftRate·step`) |
| 拔河 / 合力 | 抓着反弹物品被拔河时,用反弹后的钩尖计算;合力帮手的钩子直线连向物品,永远不反弹 |
| 设计目的 | 增加技巧上限,让人能打出漂亮的角度。射程限制和只给 ×1.25 是因为实测狂按会大量误打误撞地反弹(×1.5、不限射程时,狂按的额外奖励比熟练玩家还多) |

只有顿帧影响逻辑,其余都只影响画面和声音。

| 项 | 规则 |

| 连击音高 | 金币音效每升一档连击,音高 +1 个半音 |
| 绳子吃力 | 拉重物(≥3)时绳子轻微抖动(≤2 px),每 0.45 秒一声吱呀,音高随重量变低 |

| 减少特效 | 按 **V** 切换(存 localStorage `goldminer.reduceFx`),关掉震屏、镜头推近和闪光,右下角提示"V 特效:开/关"。**不改变任何游戏结果** |

## 3. 为什么"太容易":诊断

### 3.1 实测(当前代码,不购物,每档 40 局;"通关率"= 8 关全通的比例)

| 模式 | 狂按 | 乱按 | 新手 | 熟练 | 完美 |
|---|---|---|---|---|---|
| 合作(现目标 17,000) | **100%** | **100%** | 100% | 100% | 100% |
| 对战(每人,现目标 9,300) | **89%** | **65%** | 91% | 100% | 98% |
| 单人(一期目标 17,200) | **57%** | 0% | 52% | 100% | 98% |
| 5 个新机制直接加上、不调数值 | 所有机器人每关收入 **+55–65%**,狂按也一样涨 | | | | |

### 3.2 原因

1. **失误几乎没有代价**:空钩以 900 px/秒飞回,抓到石头最多损失几秒,而且狂按时也没有别的惩罚。所以狂按约等于新手。
2. **场地太富**:保底价值是本关增量的 2.1–2.7 倍再加 $500,再加上 28 + 1.5×关数 个物品,只要拿到一小半就能过关。
3. **白给的钱多**:神秘袋(平均约 $150 现金)、金猪 $300–500、金蛋 65% 孵出 $400、宝箱 $300–1,200,都是"价值/重量"很高的彩票,乱抓也能抓到。
4. **累计目标后段增量太小**:合作第 8 关只需要 +$3,500,而熟练双人一关能挣 $6,800。前面领先了,后面就没有压力。
5. **新机制本身也会白送**:黄金尾声随机刷在浅层、反弹 ×1.5 且不限射程、节奏不惩罚狂按,这样狂按的收入会一起暴涨。

## 4. 挑战性重做(v2 规则集,每个模式一套)

### 4.1 设计原则

- **奖励瞄准、惩罚狂按**:连击被垃圾或空钩打断;节奏踩空减速;尾声物品放在深处;反弹 ×1.25 且限射程;空钩回收变慢。
- **场地稀缺**:要拿到大约一半以上的场地价值才过关。挑哪个、躲哪个、什么时候用炸药保连击,都有了取舍。
- **目标追着高手跑**:后段每关增量接近熟练玩家的单关收入,每一关都紧张。第 1 关仍然友好,用来上手。
- **危险物数值不变,但代价变大**:被石门挡、被岩浆击退、碰 TNT 都会断连击。

### 4.3 校准结果(v2,真实失败流程,种子 1–50,不购物)

| 模式 | 狂按 | 乱按 | 新手 | 熟练 | 完美 |
|---|---|---|---|---|---|
| 单人:8 关全通 | 0% | 0% | 0% | **56%** | 96% |
| 单人:到达第 3 关 | 2% | 8% | 50% | 96% | 96% |
| 对战(每人,同水平对打) | 1% | 0% | 1% | **67%** | 91% |
| 合作 | 0% | 0% | 0% | **56%** | 100% |
| 单人平均星数(满 24) | 1.3 | 2.1 | 4.3 | 12.0 | 18.4 |

- 新手平均在第 3–4 关倒下,熟练一半能通关,完美基本都能通关,狂按完全不行。这就是"挑战来自技巧"。
- 机器人不购物。真人买大力药水、加速齿轮等能多挣一些,但商店涨价更快,花钱也会离累计目标更远,买不买是真正的取舍。

## 5. 最终得分(为第三阶段排行榜准备)

- **最终得分 = 终局时的金币**:单人是玩家金币;对战是每名玩家各自的金币;合作是团队金币(合作不上榜,只显示)。
- 终局页用大字显示"最终得分 $X",单人和对战的每个玩家都有。`G.final.scores = [{ player: 0, score, rounds, char }, …]`:
  - `rounds` = 到达的最远关数(通关 8 关记 8;在第 k 关失败或被淘汰记 k);
  - `G.final.version = RULE_VERSION`。
- 得分是非负整数(`Math.max(0, Math.round(money))`)。

## 7. 可测试性要求

1. `RULESETS`、`RULE_VERSION`、`__game.setRules(name)`(只在 start 屏生效),URL `?rules=v1|v2`。
2. 状态字段(都放在可读对象上):
   - 玩家:`p.combo`、`p.comboMult`、`p.boostT`、`p.stallT`;
   - 钩子:`h.rt`、`h.bx`、`h.by`、`h.blen`、`h.a2`、`h.neutral`;
   - 全局:`G.finaleOn`、`G.hitStop`;
   - 统计:`G.stats = { comboCatches, comboMax, comboBonus, finaleSpawned, bounceCatches, rhythmHit, rhythmMiss, hitStops, nearMiss }`,每局开始时清零。
3. 纯函数:`__game.comboMultFor(n)`、`__game.rhythmJudge(rt)`(返回 'hit' | 'miss' | 'early'),`__game.finaleCount(round)`。
4. `__game.placeItem(type, x, y)`:往当前关卡加一个物品,并检查是否重叠。`__game.setHook(pid, {angle})`:只在 swing 状态下设置摆角,用于 AC-P2-14/20 的布置。
5. 视觉随机用 `fxRand`;`__game.reduceFx(bool)`。
6. 一期的 `?seed`、`startMode`、`reseed` 等接口保留。

## 8. 需要用户拍板的问题

**Q1. 难度定位**
- 推荐:**熟练玩家约一半能通关**(本方案)。普通玩家常会在中段失败,但单人星级、最终得分和排行榜能给出"越打越好"的目标。
- 另一个选项:稍宽松一点,熟练玩家约 70% 能通关,所有目标约 −6%。

**Q2. 拉重物时乱按会被惩罚(踩空减速),可以吗?**
- 推荐:**可以**。这是让"狂按过关"失效的关键之一。
- 另一个选项:踩空只是不加速、不减速。但实测这样狂按的收益会回升,需要再提高目标。

**Q3. 倍率叠加要不要封顶?**
- 推荐:**不封顶**。四叶草 ×2 × 连击 ×2 × 反弹 ×1.25 最高 ×5,难得出现一次,是高光时刻。
- 另一个选项:总倍率封顶 ×3,更稳,但少了"爆一把"的爽感。
